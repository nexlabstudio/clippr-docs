## Getting Started

### 1. Create an Organization

Organizations are workspaces that contain your apps, links, and team members.

1. Sign in at [app.useclippr.xyz](https://app.useclippr.xyz)
2. Click **Create Organization**
3. Enter your organization name and slug

### 2. Create an App

Apps represent your mobile applications.

1. Go to **Apps** → **Create App**
2. Enter your app name and subdomain
3. Configure iOS and/or Android settings
4. Copy your API key for SDK integration

### 3. Create Links

Start creating deep links for your app.

1. Go to **Links** → **Create Link**
2. Enter the deep link path
3. Add attribution and social tags
4. Share your link!
